# Prototype (M3) — ต้นแบบหน้าจอที่คลิกได้

> **วิธีเปิด:** ดับเบิลคลิก [`index.html`](index.html) (สารบัญ + ตารางครอบคลุม AC 43 ข้อ) · [`demo.html`](demo.html) (จอผู้สูงอายุกับจอผู้ดูแลคู่กัน มีนาฬิกาจำลอง) · [`app.html`](app.html) (จอเดียว สลับบทบาท) — ไม่ต้องมี server ไม่ต้องติดตั้งอะไร · ข้อจำกัดและหน้าจอ ↔ FR: [`NOTES.md`](NOTES.md) · รายการทดสอบด้วยมือ: [`TEST-CHECKLIST.md`](TEST-CHECKLIST.md)
> โฟลเดอร์นี้เคยอยู่ที่ `docs/02-design/prototypes/2569-11-04/` ย้ายมาไว้ที่ `prototype/` เมื่อ 9 พ.ย. 2569 ตามโครง repo ที่อาจารย์กำหนด (Git for Teams §6, §9) — ประวัติไฟล์ดูได้ด้วย `git log --follow`
> ต้นแบบนี้คือส่วน **Design (M3)** · ระบบจริงที่ใช้ตรรกะชุดเดียวกับโค้ดส่งคือ [`public/`](../public/) (`demo.html` = Demo mode ADR-8, `senior.html` / `caregiver.html` = ใช้งานจริงบน Firebase)

## เกณฑ์ที่ต้องผ่าน (สไลด์ M3 §8, §13 และ M4 §2) — ตรวจอัตโนมัติด้วย `tests/prototype.test.js`
| # | เกณฑ์ | ตรวจอย่างไร |
|---|---|---|
| 1 | เปิดในเบราว์เซอร์ได้ **ไม่ต้องมี server/DB** (ไฟล์ HTML ที่คลิกได้) | ดับเน็ตแล้วดับเบิลคลิกไฟล์ |
| 2 | ใช้ **token จาก `css/tokens.css` เท่านั้น** ไม่ใส่สีลอย (`#3b82f6`) | ค้น hex ใน CSS/JS ต้องอยู่เฉพาะที่ประกาศ token |
| 3 | มี **ทางที่ผิด**: empty / error / ออฟไลน์ ตาม AC ของ SRS | เปิดสถานะเหล่านั้นได้จากไฟล์ |
| 4 | **ทุกหน้ามีแถบ "Covers: FR-xx"** และชี้กลับ FR/BR/NFR ได้ | มีทุกหน้า |
| 5 | คลิกเดินได้ครบ **ทุก Must FR (FR-01 ถึง FR-05)** จัดตาม user journey | ไล่ตาม Screen Map ใน `docs/02-design/design-system.md` §4 |
| 6 | ข้อความถึงผู้ดูแลตรงกับ SRS (`ยังไม่ยืนยันการกินยา` ห้าม `ไม่ได้กิน`) | ค้นคำใน copy |
| 7 | ใช้ข้อมูลสมมติเท่านั้น ไม่มีฉลากหรือชื่อ/HN ผู้ป่วยจริง | ตรวจก่อน commit (`npm run check`) |
| 8 | README บอกวิธีเปิด | ไฟล์นี้ |

## โครงไฟล์

