## หน้าตา (ปรับ 4 พ.ย.)
- **สี: โทนเขียวตามต้นแบบของ Rossatorn** (ผู้ใช้ไม่เอาโทนม่วงฟ้าที่ลองไว้) — แก้ token ใน `css/tokens.css` และ `design-system.md` §2 ให้ตรงกัน **ตรวจ contrast ใหม่ทุกคู่ ≥ 4.5 : 1** · ปุ่ม "กินแล้ว" เขียว / "ยังไม่กิน" แดง (BR-09)
- **การ์ดมุมมน แถบล่างมีไอคอน** (แนวจากภาพที่ทีมทำด้วย ChatGPT) · ไอคอนและโลโก้วาดเองเป็น SVG · มาสคอตจากต้นแบบของ Rossatorn (หัวข้อถัดไป)
- **ไม่เอามาจากภาพแนวทางเพราะขัด SRS:** เข้าสู่ระบบ/สมัครสมาชิก (BR-02) · คำว่า "ลืมกินยา" (BR-13) · ปุ่ม "รับทราบ/เลื่อนเวลา" (BR-08) · รูปยาบนหน้าเตือน (FR-03 ข้อ 1) · เคล็ดลับสุขภาพ (ห้ามแนะนำทางการแพทย์) · ชื่อจริงผู้สูงอายุ เบอร์โทรฉุกเฉิน สถานะ "ออนไลน์" (NFR-09) · รายงานรายสัปดาห์/ประวัติหลายวัน (FR-09, FR-07 = Could) · สแกน QR/บาร์โค้ดบนฉลาก (BR-19) — รายการเดียวกันอยู่ใน `design-system.md` §2
- **หน้าตั้งค่า (S-04 / C-09) ปรับการแสดงผลได้รายเครื่อง:** ขนาดตัวอักษร 3 ระดับ (ปกติ/ใหญ่/ใหญ่มาก — ไม่ต่ำกว่าเกณฑ์ NFR-03) และโหมดสว่าง/มืด · ขนาดตัวอักษรตามที่ design-system.md ระบุไว้แล้วใน S-04 ส่วนโหมดมืด **ไม่ใช่ requirement ใน SRS** เป็นตัวเลือกของต้นแบบ
- **ไอคอนจากชุด `medmind-icons` ที่ทีมส่งมา** (SVG เส้นมน stroke 1.8): หน้าหลัก (`home`) · แจ้งเตือน (`notification`) · ตั้งค่า (`settings` ฟันเฟือง) · ขนาดตัวอักษร (`font-plus` / `font-minus`) · ธีม (`theme-light` / `theme-dark`) — ฝังใน `js/ui.js` ใช้ `currentColor` ตามสี token (ไม่ใส่ #hex) · ฟันเฟืองขยายให้ขนาดเท่าไอคอนอื่น · ไอคอนสถานะ/ยาของแถบล่างผู้ดูแลยังเป็นของเดิม (ชุดนี้ไม่มี)
- **แถบล่าง:** ผู้สูงอายุมีข้อความสั้นใต้ไอคอน (หน้าหลัก · เตือน · ตั้งค่า) เพราะไอคอนอย่างเดียวผู้สูงอายุอาจเดาไม่ออก · ขนาด `--fs-tab` 18 / 19 / 20 px ตามระดับตัวอักษร — โตช้ากว่าตัวอักษรหลักให้พอดี 3 ปุ่มในจอ แต่ไม่ต่ำกว่า 18px (NFR-03) · ผู้ดูแลเป็นไอคอนอย่างเดียว · ทุกปุ่มมี `aria-label` และ `title`
- ทักทาย "สวัสดี" ไม่มีชื่อ เพราะระบบไม่เก็บชื่อผู้สูงอายุ (NFR-09)

- ถ้าเพื่อนเจ้าของต้นแบบเก่านำไฟล์เข้ามาภายหลัง ให้เลือกชุดที่ดีกว่า หรือรวมกัน แล้วบันทึกใน decision-log

## ข้อจำกัด (พูดตรง ๆ)
- ข้อมูลและเวลาเป็นของจำลอง **ไม่มี Firebase / AI จริง / กล้อง** — ภาพฉลากเป็นกรอบ HTML สมมติ (ไม่มีรูปจริงและไม่มีชื่อ/HN จริง)
- กฎเวลาใน `js/mock.js` เป็นสำเนาย่อของ `architecture.md` §5.1 เพื่อสาธิตเท่านั้น — ตรรกะจริงอยู่ที่ `public/js/logic/` (เจ้าของ FR เขียนและมีเทสต์) ถ้าสัญญาเปลี่ยนต้องแก้ทั้งสองที่
- รหัสจับคู่เป็นค่าตายตัวสี่ค่าสลับกัน · QR เป็นภาพตัวอย่าง ไม่ใช่ QR จริง
- เสียงเตือนใช้ Web Audio (ดังหลังแตะครั้งแรก) ยังไม่ได้ทดสอบบนมือถือจริง (MT-04, MT-18)
- ยังไม่ได้ตรวจ contrast/ขนาดด้วย DevTools บนเบราว์เซอร์จริง (MT-08): ใช้ token ที่ตรวจแล้วใน `design-system.md` และเทสต์ยืนยันว่าอ้าง token ถูกตัว

## การใช้ AI (ตามกติกา RULES §4 — ต้องบันทึกตามจริง)
- ต่อยอดจากต้นแบบของ Rossatorn (สร้างด้วย OpenAI Codex ตามบันทึกในต้นฉบับ) · ภาพแนวทางหน้าตา (โทนม่วงฟ้า) ทีมสร้างด้วย ChatGPT · Claude Code ปรับ token ตรวจ contrast และวาดไอคอน SVG
- ใช้ Claude Code ร่างโครงและโค้ดทั้งชุด ตามคำสั่งและตัวเลือกของเจ้าของงาน (สร้างใหม่ทั้งชุด, ทำในฐานะเจ้าของต้นแบบ)
- AI ทดสอบเองด้วยเบราว์เซอร์จำลอง (Playwright) ว่าคลิกเดินครบและกฎเวลาตรงเทสต์ — **เจ้าของงานยังต้องเปิดเล่นเองทุกหน้า ทั้งบนคอมและมือถือ**
