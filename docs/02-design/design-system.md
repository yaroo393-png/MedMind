# Design System & Screen Map — MedMind

> **ฉบับร่างเริ่มต้น 31 ต.ค. 2569** — ร่างด้วย AI จาก SRS (NFR-02, NFR-03, FR-01–05) UX/UI Designer ต้องตรวจ ปรับ และเพิ่มภาพหน้าจอ/ต้นแบบใน `docs/02-design/diagrams/` · ทุกตัวเลขขนาด/สีต้องผ่านเกณฑ์ NFR-03 (ตรวจด้วย DevTools + ตัวตรวจ contrast)

## 1. หลักการออกแบบ
1. **ผู้สูงอายุ: แตะน้อย ตัวใหญ่ ไม่ต้องพิมพ์ ไม่ต้องสมัคร** (ผู้ให้สัมภาษณ์ 1, 3) — หน้าเตือนมีแค่ 2 ปุ่ม
2. **ผู้ดูแล: เห็นเฉพาะสิ่งที่ต้องรู้** — แจ้งเมื่อมื้อยังไม่ยืนยันเท่านั้น (ผู้ให้สัมภาษณ์ 2) และไม่ใช้คำว่า "ไม่ได้กิน" (ใช้ "ยังไม่ยืนยัน" ตาม BR-13)
3. **ไม่เดา:** ช่องที่ AI อ่านไม่ชัดต้องว่างและมีป้าย "Please check" (BR-04)
4. **ห้ามสีเดียวสื่อความหมาย:** ปุ่มเขียว/แดงต้องมีข้อความกำกับเสมอ
5. ทุกหน้ามีป้าย "Covers: FR-xx" (ดูหัวข้อ 5)

#### รายละเอียดหน้าเลือกบทบาท (S-00)
หน้านี้ไม่ใช่ FR ของตัวเอง แต่จำเป็นต่อ FR-01 (ต้องรู้ว่าเครื่องนี้เป็นผู้สูงอายุหรือผู้ดูแลก่อนจับคู่) จึงติดป้าย "Covers: FR-01"

| เรื่อง | กติกา |
|---|---|
| แสดงเมื่อไร | เปิดแอปครั้งแรกบนเครื่องที่ยังไม่มีบทบาท · ถ้ามีบทบาทแล้ว พาไป `senior.html` / `caregiver.html` เลย · **เปิดจากลิงก์ QR** (`caregiver.html?code=…`) → ข้ามหน้านี้ ตั้งเป็นผู้ดูแลให้อัตโนมัติ |
| หน้าตา | การ์ดใหญ่ 2 ใบ (สูง ≥ 64 px, ตัวอักษร ≥ 18 px): **"ผู้สูงอายุ — ใช้เครื่องนี้รับการเตือนกินยา"** และ **"ผู้ดูแล / ลูกหลาน — ใช้เครื่องนี้ดูสถานะและเพิ่มยา"** · คำแนะนำสั้น: "ถ้าตั้งค่าให้พ่อแม่ ให้เลือก ผู้สูงอายุ บนมือถือของท่าน" (ผู้ดูแลเป็นคนตั้งค่าหลัก, SRS §2.2) · ไม่ต้องสมัคร ไม่ต้องพิมพ์ |
| หลังเลือก | ยืนยัน 1 ครั้ง ("เครื่องนี้จะใช้สำหรับ … เปลี่ยนภายหลังได้ในหน้าตั้งค่า") → Anonymous sign-in → **ผู้สูงอายุ:** สร้าง pair + รหัสเชิญ แล้วไป `senior-pair` · **ผู้ดูแล:** ไป `caregiver-pair` (สแกน QR ด้วยแอปกล้อง หรือกรอกรหัส) |
| เก็บอะไร | บทบาทในเครื่อง (`localStorage`) เพื่อพาไปหน้าที่ถูก · ความจริงอยู่ที่ Firestore: uid ตรงกับ `seniorUid` หรือ `caregiverUid` ของ pair ไหน · ล้างข้อมูลเบราว์เซอร์ → กลับมาหน้านี้และต้องจับคู่ใหม่ (SRS §2.2) |
| เปลี่ยนบทบาท | ทำได้ในหน้าตั้งค่า **เฉพาะตอนยังไม่จับคู่** · ถ้าจับคู่แล้วต้องยกเลิกจับคู่ก่อน (BR-17) — กันไม่ให้เครื่องเดียวเป็นสองบทบาท (MVP: 1 ผู้สูงอายุ ต่อ 1 ผู้ดูแล) |
| กรณีพิเศษ | เปิด `senior.html` / `caregiver.html` ตรง ๆ โดยยังไม่มีบทบาท → พากลับหน้านี้ · เครื่องที่เป็นผู้สูงอายุอยู่แล้วเปิดลิงก์ QR → เตือน "เครื่องนี้ตั้งเป็นผู้สูงอายุ" ไม่สลับเอง · ไม่มีเน็ตตอนเปิดครั้งแรก → "ต้องต่ออินเทอร์เน็ตครั้งแรกเพื่อเริ่มใช้งาน" + ปุ่มลองใหม่ · `demo.html` ไม่ผ่านหน้านี้ |

## 5. ป้าย "Covers" และข้อความ
- ทุกหน้า HTML มี `<p class="covers">Covers: FR-03, BR-08, BR-09</p>` (อาจซ่อนด้วยปุ่ม "debug" ตอนเดโมจริง) เพื่อให้ตรวจ Golden Thread ได้
- ข้อความถึงผู้ดูแลต้องคงความหมายตาม SRS (BR-13): ไทย "ยังไม่ยืนยันการกินยา" = `Medicine not yet confirmed` · "ยืนยันการกินยาแล้ว เวลา HH:MM" = `Medicine confirmed at HH:MM` · **ห้ามใช้ "ไม่ได้กิน"**
- ปุ่มสถานะ: "กินแล้ว" (`Taken`) / "ยังไม่กิน" (`Not yet`) · ข้อความผู้ใช้ทุกอย่างต้อง escape ก่อนใส่ HTML
