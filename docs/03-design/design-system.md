## 1. Tokens

แนวหน้าตา: พื้นเทาอ่อน + แถบหัวสีมิ้นต์ หัวข้อตัวใหญ่ การ์ดสีขาวมุมมน ปุ่มทรงแคปซูล และปุ่มหลักยาวเต็มด้านล่างจอ (อ้างอิงโทนสีจากภาพตัวอย่างแอปเตือนกินยาที่ทีมเลือก) · ทุกสีตรวจ contrast แล้ว (§1.4) — สีพาสเทลในภาพตัวอย่างใช้เป็นพื้นเท่านั้น ไม่ใช้กับตัวอักษรสีขาว เพราะ contrast ไม่ถึง 4.5:1

### 1.4 ความต่างสี (NFR-03: ≥ 4.5:1)

คำนวณด้วยสูตร contrast ratio ของ WCAG 2.2 จากค่าสีในตารางด้านบน — ยังไม่ได้วัดซ้ำบนหน้าจริงด้วยตัวตรวจ contrast · ค่าเดียวกันอยู่ใน [`prototype/src/tokens.css`](../../prototype/src/tokens.css)

| คู่สี | Contrast | ผ่าน ≥ 4.5:1 |
|---|---|---|
| ตัวขาวบนปุ่ม "กินแล้ว" `#15803D` | 5.02 : 1 | ✓ |
| ตัวขาวบนปุ่ม "ยังไม่กิน" `#BE123C` | 6.29 : 1 | ✓ |
| ตัวขาวบนปุ่มหลัก `#0F766E` | 5.47 : 1 | ✓ |
| ข้อความหลักบนการ์ดขาว | 11.48 : 1 | ✓ |
| ข้อความหลักบนพื้นหน้า | 10.32 : 1 | ✓ |
| ข้อความหลักบนแถบมิ้นต์ | 8.81 : 1 | ✓ |
| ข้อความหลักบนพื้นรายการยา `#E4F3EE` | 10.04 : 1 | ✓ |
| หัวข้อใหญ่ `#0F5F58` บนแถบมิ้นต์ | 5.75 : 1 | ✓ |
| ข้อความรองบนการ์ดขาว | 7.56 : 1 | ✓ |
| ข้อความรองบนพื้นหน้า | 6.79 : 1 | ✓ |
| ป้าย "กินแล้ว" | 8.30 : 1 | ✓ |
| ป้าย "กินแล้ว (ยืนยันช้า)" | 8.41 : 1 | ✓ |
| ป้าย "กำลังเตือน" | 8.49 : 1 | ✓ |
| ป้าย "ยังไม่ยืนยัน" | 8.32 : 1 | ✓ |
| ป้าย "รอถึงเวลา" | 9.37 : 1 | ✓ |
| ช่อง "กรุณาตรวจสอบ" | 6.37 : 1 | ✓ |
| ลิงก์บนการ์ดขาว | 5.47 : 1 | ✓ |
| แถบ "Covers: FR-x" | 11.48 : 1 | ✓ |

ปุ่ม "กินแล้ว" กับ "ยังไม่กิน" ต่างกันทั้งสีและข้อความ — ไม่ใช้สีอย่างเดียวบอกความหมาย (สำหรับผู้ที่แยกสีเขียว/แดงไม่ออก)

## 2. Screen Map: หน้าจอ ↔ FR

ทุกหน้ามีแถบ **"Covers: FR-x"** บนสุด เพื่อชี้ได้ตอน demo ว่าหน้านี้ = requirement ข้อไหน · ภาพหน้าจอจาก [`prototype/index.html`](../../prototype/index.html)

| รหัส | หน้าจอ | ผู้ใช้ | Covers | องค์ประกอบหลัก | ภาพหน้าจอ |
|---|---|---|---|---|---|
| S1 | เริ่มต้น / QR + ยินยอม | Senior | FR-01 | QR + รหัสเชิญ 6 หลัก (ไม่ต้องสมัครหรือพิมพ์) · ปุ่ม "ยินยอม" · ปุ่ม "สร้างรหัสใหม่" | ![S1](screens/S1-qr-consent.png) |
| C1 | จับคู่ + ยกเลิกการจับคู่ | Caregiver | FR-01 | สแกน QR หรือใส่รหัส 6 หลัก · ผลจับคู่ "เชื่อมต่อแล้ว" · ปุ่ม "ยกเลิกการจับคู่" | ![C1](screens/C1-pairing.png) |
| C2 | สแกนฉลาก → ร่าง → ตั้งเวลามื้อ | Caregiver | FR-02 | ถ่ายรูปฉลาก · ฟอร์มร่าง (ชื่อยา, จำนวนเม็ดต่อครั้ง, มื้อ/เวลา, ข้อควรระวัง, ข้อห้ามใช้) · ตั้งเวลามื้อเช้า/กลางวัน/เย็น + เวลาเข้านอน · ปุ่ม "บันทึก" / "ยกเลิก" | ![C2](screens/C2-draft-check.png) |
| S2 | หน้าเตือน | Senior | FR-03, FR-04 | เวลามื้อ · ยาทุกตัวในมื้อ (ชื่อยา 24 px, จำนวนเม็ด, ข้อควรระวัง, ข้อห้ามใช้) · ปุ่ม "กินแล้ว" (เขียว) / "ยังไม่กิน" (แดง) · เสียงเตือน · ไม่มีรูปยา | ![S2](screens/S2-reminder.png) |
| S3 | หน้าแรก | Senior | FR-04 (BR-15) | มื้อของวันพร้อมป้ายสถานะ · ปุ่ม "กินแล้ว" สำหรับมื้อที่อยู่ในช่วงยืนยันช้า · จุดแตะเพื่อเปิดเสียงครั้งแรก · ลิงก์ "ยกเลิกการจับคู่" (BR-17) | ![S3](screens/S3-home-late.png) |
| C3 | แจ้งเตือน + สถานะรายวัน | Caregiver | FR-05 | ข้อความ "ยังไม่ยืนยันการกินยา" / "ยืนยันการกินยาแล้ว เวลา …" · รายการทุกมื้อของวันพร้อมป้ายสถานะ 5 แบบ (§1.1) | ![C3](screens/C3-status.png) |

**เส้นทางผู้ใช้ (user journey)**
- Caregiver: C1 จับคู่ → C2 เพิ่มยา → C3 ดูสถานะ / รับการแจ้งเตือน
- Senior: S1 ยินยอม → S3 หน้าแรก → S2 หน้าเตือนเมื่อถึงเวลา → กลับ S3
