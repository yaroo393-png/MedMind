### 1.4 ความต่างสี (NFR-03: ≥ 4.5:1)

คำนวณด้วยสูตร contrast ratio ของ WCAG 2.2 จากค่าสีในตารางด้านบน — วัดซ้ำบนหน้าจริงของ prototype ด้วยตัวตรวจ contrast อีกครั้งเมื่อ prototype เสร็จ

| คู่สี | Contrast | ผ่าน ≥ 4.5:1 |
|---|---|---|
| ตัวขาวบนปุ่ม "กินแล้ว" `#15803D` | 5.02 : 1 | ✓ |
| ตัวขาวบนปุ่ม "ยังไม่กิน" `#B91C1C` | 6.47 : 1 | ✓ |
| ตัวขาวบนปุ่มหลัก `#1D4ED8` | 6.70 : 1 | ✓ |
| ข้อความหลักบนการ์ด | 17.74 : 1 | ✓ |
| ข้อความหลักบนพื้นหน้า | 16.96 : 1 | ✓ |
| ข้อความรองบนการ์ด | 7.56 : 1 | ✓ |
| ข้อความรองบนพื้นหน้า | 7.22 : 1 | ✓ |
| ป้าย "กินแล้ว" | 8.30 : 1 | ✓ |
| ป้าย "กินแล้ว (ยืนยันช้า)" | 8.41 : 1 | ✓ |
| ป้าย "กำลังเตือน" | 8.49 : 1 | ✓ |
| ป้าย "ยังไม่ยืนยัน" | 8.20 : 1 | ✓ |
| ป้าย "รอถึงเวลา" | 9.37 : 1 | ✓ |
| ช่อง "กรุณาตรวจสอบ" | 6.37 : 1 | ✓ |
| ลิงก์บนการ์ด | 6.70 : 1 | ✓ |

## 2. Screen Map: หน้าจอ ↔ FR

ทุกหน้ามีแถบ **"Covers: FR-x"** บนสุด เพื่อชี้ได้ตอน demo ว่าหน้านี้ = requirement ข้อไหน · ภาพหน้าจอใส่เมื่อ prototype เสร็จ

| รหัส | หน้าจอ | ผู้ใช้ | Covers | องค์ประกอบหลัก | ภาพหน้าจอ |
|---|---|---|---|---|---|
| S1 | เริ่มต้น / QR + ยินยอม | Senior | FR-01 | QR + รหัสเชิญ 6 หลัก (ไม่ต้องสมัครหรือพิมพ์) · ปุ่ม "ยินยอม" · ปุ่ม "สร้างรหัสใหม่" | (รอ prototype) |
| C1 | จับคู่ + ยกเลิกการจับคู่ | Caregiver | FR-01 | สแกน QR หรือใส่รหัส 6 หลัก · ผลจับคู่ "เชื่อมต่อแล้ว" · ปุ่ม "ยกเลิกการจับคู่" | (รอ prototype) |
| C2 | สแกนฉลาก → ร่าง → ตั้งเวลามื้อ | Caregiver | FR-02 | ถ่ายรูปฉลาก · ฟอร์มร่าง (ชื่อยา, จำนวนเม็ดต่อครั้ง, มื้อ/เวลา, ข้อควรระวัง, ข้อห้ามใช้) · ตั้งเวลามื้อเช้า/กลางวัน/เย็น + เวลาเข้านอน · ปุ่ม "บันทึก" / "ยกเลิก" | (รอ prototype) |
| S2 | หน้าเตือน | Senior | FR-03, FR-04 | เวลามื้อ · ยาทุกตัวในมื้อ (ชื่อยา 24 px, จำนวนเม็ด, ข้อควรระวัง, ข้อห้ามใช้) · ปุ่ม "กินแล้ว" (เขียว) / "ยังไม่กิน" (แดง) · เสียงเตือน · ไม่มีรูปยา | (รอ prototype) |
| S3 | หน้าแรก | Senior | FR-04 (BR-15) | มื้อของวันพร้อมป้ายสถานะ · ปุ่ม "กินแล้ว" สำหรับมื้อที่อยู่ในช่วงยืนยันช้า · จุดแตะเพื่อเปิดเสียงครั้งแรก · ลิงก์ "ยกเลิกการจับคู่" (BR-17) | (รอ prototype) |
| C3 | แจ้งเตือน + สถานะรายวัน | Caregiver | FR-05 | ข้อความ "ยังไม่ยืนยันการกินยา" / "ยืนยันการกินยาแล้ว เวลา …" · รายการทุกมื้อของวันพร้อมป้ายสถานะ 5 แบบ (§1.1) | (รอ prototype) |

**เส้นทางผู้ใช้ (user journey)**
- Caregiver: C1 จับคู่ → C2 เพิ่มยา → C3 ดูสถานะ / รับการแจ้งเตือน
- Senior: S1 ยินยอม → S3 หน้าแรก → S2 หน้าเตือนเมื่อถึงเวลา → กลับ S3

## 3. Error / Empty states

| หน้าจอ | กรณี | สิ่งที่แสดง | อ้างอิง |
|---|---|---|---|
| C1 | Senior ยังไม่กดยินยอม | "รอผู้สูงอายุกดยินยอม" · ยังไม่เชื่อมต่อ | FR-01 ✗2 |
| C1 | รหัสผิด / เกิน 10 นาที / ใช้แล้ว | "รหัสไม่ถูกต้องหรือหมดอายุ ขอรหัสใหม่จากผู้สูงอายุ" · ไม่เชื่อมต่อ | FR-01 ✗4, BR-01 |
| C1 | Senior มีผู้ดูแลแล้ว | "ผู้สูงอายุท่านนี้มีผู้ดูแลแล้ว" · ไม่เชื่อมต่อ | FR-01 ✗5, BR-02 |
| C1, S3 | กดยกเลิกการจับคู่ | กล่องยืนยันอีกครั้ง "ข้อมูลยาและประวัติการยืนยันจะถูกลบ" · ปุ่มยืนยัน (แดง) / ยกเลิก · หลังยืนยัน Senior เห็น QR ใหม่ | FR-01 ✗6, BR-17 |
| C1, C2 | ไม่อนุญาตใช้กล้อง | C1: ใช้ช่องใส่รหัส 6 หลักแทน · C2: เปิดฟอร์มให้กรอกเอง | SRS §2.2 |
| C2 | มีช่องที่อ่านไม่ได้ / ฉลาก "ก่อนอาหาร" ไม่ระบุนาที | ช่องว่าง + ป้าย "กรุณาตรวจสอบ" (สี §1.1) · ปุ่ม "บันทึก" กดไม่ได้จนช่องบังคับครบ | FR-02 ✗3, ✗10, BR-04 |
| C2 | ฉลากเป็นยาที่กินเมื่อมีอาการ | "ระบบยังไม่รองรับยาเมื่อมีอาการ" · ไม่สร้างตาราง | FR-02 ✗4, BR-07 |
| C2 | สแกนล้มเหลว | ฟอร์มว่างให้กรอกเอง | FR-02 ✗5 |
| C2 | กด "ยกเลิก" ในหน้าร่าง | กลับหน้าก่อน · ไม่บันทึกอะไร | FR-02 ✗7 |
| S2 | มื้อเวลาซ้อนกัน | แสดงทุกมื้อที่ยังไม่ยืนยัน เรียงตามเวลา แยกหัวข้อ แต่ละมื้อมีปุ่มของตัวเอง · เสียงครั้งเดียว | FR-03 ✗4, BR-16 |
| S2, S3 | ยังไม่ได้แตะหน้าจอหลังเปิด (เบราว์เซอร์ยังไม่ให้เล่นเสียง) | แถบ "แตะหน้าจอเพื่อเปิดเสียงเตือน" | SRS §2.2, ADR-01 |
| S3 | เลยช่วงยืนยันช้าแล้ว | ไม่มีปุ่ม "กินแล้ว" · ป้ายคง "ยังไม่ยืนยัน" | FR-04 ✗6, BR-15 |
| C3 | ยังไม่มีมื้อยาในวัน | "ยังไม่มีมื้อยาวันนี้" | FR-05 ✗4 |
